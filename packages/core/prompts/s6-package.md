## 编排要求
1. **头条、按公司聚类与导览对齐（重磅主流模型、顶尖突破或全局大事优先头条）**：将全部已通过新闻条目 ID 排入 `order`（长度必须等于输入条目数、且包含每个输入条目 ID，头条放第一），`headlineItemId` 必须等于 `order[0]`；**同等重要度下，仅当本期包含大众高度关注的主流核心模型（如 `GPT`、`Claude`、`Gemini`、`DeepSeek`、`GLM`、`Qwen` 等主力系列）重磅发布或真正业内顶尖/现象级破圈模型时，优先排在前面并优先作为头条**，在 `headline`、`publish.title` 与 `cover` 中直接突出具体模型名与核心亮点；若是能力比较一般、偏小众或衍生型普通模型，应放到靠后位置，**严禁**让一般模型抢占主流顶尖模型、重大实用产品更新或全局性行业大事件（如头部公司 IPO、创纪录融资、核心人事地震、重大安全隐私或政策事件）的头条与前排要闻位。`headline` 语气简明有力。同时，为了让正片播报顺畅且与开头瀑布流导览顺序完全一致，请严格遵循以下排布结构：
   - **开头要闻（前 1～2 条）**：共 5 条及以上时前 2 条为要闻（4 条及以内时第 1 条为要闻），放置本期最重磅、关注度最高的新闻；
   - **其余条目按所属公司聚类连续排列**：同一家公司或机构的多条新闻必须紧挨着连续排在一起（如 Google 的多条连排、OpenAI 的多条连排），不同公司组按该组最高重要度条目的顺位从高到低排列，零散单条小机构排在末尾。
2. **极简开场（`intro`）**：**只做符合主播性格的问候、自我介绍与开播引导，严禁总结、概括、罗列或预告任何一条具体新闻内容**（封面画面已经列出瀑布流总览，口播绝不再复读目录）：
   - `intro.narration` 严格控制在 **1～2 句、总长 18～58 字**，按当期主播 `selfName` 与性格口吻（`speakingStyle` / `introExamples`）简短干脆介绍自己（**直接说我是谁，比如“大家好，我是哈基米”，不要说自己是哪个公司的**），可用半句贴合主播性格的轻快调侃或开播态度过渡入正片（可结合 `{{dateDisplay}}`）；
   - 参考语气范式（仅作风格参考，请贴合当期主播性格自然现写）：
     - `["大家好，我是聪明的大肥鱼，今天咱们来盘一盘AI圈又整了什么新活，下面直接看报道。"]`
     - `["各位观众好，今天是11月18日周三，我是哈基米，欢迎收看AI每日报。", "屏幕上是今天的主要内容，咱们直接开聊。"]`
   - 合成时系统会自动在数组各句间添单个空格，单句内部严禁在中英文、数字、单位或标点之间滥用空格；附带一句简短、带主播性格味儿的 `intro.hostComment`。
3. **利落带性格的结尾（`outro`）**：**不做长篇趋势总结或说教升华**，像有态度的熟人主播一样带点性格收尾道别：
   - `outro.narration` 严格控制在 **1～2 句、总长 10～45 字**，可顺着本期真实看点加半句符合主播性格的轻吐槽或调侃后再干脆道别（如爱算账的聪明的大肥鱼吐槽算力成本/会员价、元气直爽的哈基米调侃付费门槛、小克冷静收束，如 `["今天的新闻账先算到这儿，我是聪明的大肥鱼，明天见。"]` 或 `["看了一圈又是一堆顶配门槛，我是哈基米，明天见！"]`），单句内部严禁滥用空格；
   - `outro.cta` 写一句克制自然的屏幕互动提示（如“哪一条最让你想吐槽？欢迎在评论区聊聊。”），`outro.hostComment` 简短贴合角色性格与吐槽口吻。
4. **B 站投稿包装（`publish`）**：
   - `publish.title` **采用多样化、自然耐看、高信息密度的 B 站科技资讯标题（20～72 字，严格不得超过平台上限 `titleMax`）**：
     - **严禁死板栏目头与烂大街模板词**：**绝不准**以 `AI每日报｜`、`AI早报：`、`今日AI资讯盘点` 等栏目名开头；**同时严禁反复套用 `AI圈大地震`、`深夜炸裂`、`白嫖开闸`、`AI圈裂开`、`诸神之战前夜`、`史诗级翻车`、`杀疯了`、`砸出`、`祭出`、`掀桌` 这类已经极度同质化的网文模板词**！不要每期都强行用“四字感叹号 + 正文 + 感叹号”的单一格式。
     - **多风格自由切换（结合本期最核心看点选用最贴切的一种，且与下方“近期历史标题”明显拉开差异）**：
       1. **干脆双拼直给型（最通用、耐看、无需硬加感叹号）**：直接用分号或逗号亮出 1～2 条最硬核的新闻主体、具体模型/产品名与核心变化，如 `Anthropic 813亿美元创史上最大IPO；Mac版Gemini上线后台电脑操控`、`OpenAI 12月起ChatGPT与Codex共享额度，Pro各档用量翻倍`；
       2. **价格/额度/数据直击型（适合降价、免费额度、参数与性能突破）**：把具体数字、价格差或福利放到最前，如 `阿里云Token Plan Pro月费降至312元；OpenCode支持微信支付购高额GLM额度`；
       3. **反差/反转冲突型（适合安全争议、翻车回应、言行对比）**：用直接陈述把矛盾摊开，如 `募资813亿美元创IPO纪录，Anthropic安全信托却无权叫停模型`；
       4. **悬念提问/吃瓜型（适合人事地震、战略转向、行业悬念）**：用观众真正关心的问题切入，如 `黄仁勋辞任一周20万人请愿回归，英伟达为何急着提前全员涨薪？`；
       5. **突发快讯型（仅限真正超级大事件）**：直接用 `突发：` 或围绕事件本身现写的短促词切入，如 `突发：DeepSeek开放全家桶API，TTS、ASR与OCR同步上线`。
     - **标点与事实红线**：使用正常中文标点（`；`、`，`、`：`、`？`、`！`）与正常空格，不必每条都用感叹号，**严禁使用文件名下划线 `_` 代替空格或标点**；标题里的全部公司名、模型代号、参数、价格、日期与人物回应**必须 100% 源自下方已过审新闻中的真实事实**，严禁造谣夸大。

   - `publish.tags` 只填本期高相关新标签，数量不得超过额外标签配额上限。
5. **视频封面文字（`cover`）**：封面左侧放一行特大字主标题、下面一条黑底副标题，右侧是当期主播立绘；观众在信息流里只看一眼小图，所以要短、要狠、要一眼看懂：
