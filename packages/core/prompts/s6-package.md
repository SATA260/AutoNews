## 编排要求
1. **头条、按公司聚类与导览对齐（重磅主流模型、顶尖突破或全局大事优先头条）**：
   - 将全部已通过新闻条目 ID 排入 `order`（长度必须等于输入条目数、且包含每个输入条目 ID，头条放第一），`headlineItemId` 必须等于 `order[0]`；
   - **同等重要度下，仅当本期包含大众高度关注的主流核心模型（如 `GPT`、`Claude`、`Gemini`、`DeepSeek`、`GLM`、`Qwen` 等主力系列）重磅发布或现象级破圈事件时，优先排在头条**；严禁让小众或衍生普通模型抢占主流旗舰模型、重大实用产品更新或全局性行业大事件的头条位；
   - **开头要闻（前 1～2 条）**：共 5 条及以上时前 2 条为要闻（4 条及以内时第 1 条为要闻）；其余条目按所属公司聚类连续排列，不同公司组按最高重要度从高到低排列，零散单条排在末尾。
   - 若本期为大事件主推专场（`issueMode` 为 `spotlight`），在 `headline`、`publish.title` 与 `cover` 中全力聚焦头条大事，不分散焦点。
2. **按主播人设打招呼开场（`intro`，报日期与名字后直接进正文）**：
   - 视频开场画面（封面概览页）上**已经完整展示“本期看点”**，因此开场口播**不要逐条念新闻、不要提前剧透或总结新闻内容**，打完招呼直接切入正片第一条新闻；
   - **`intro.narration` 控制在 1～2 句、总长 18～50 字**（每句不超过字数上限），严格结合当期主播人设（`speakingStyle`、`coreTrait` 与 `introExamples` 的语气方向）现写有活人感的开场招呼，且必须同时包含：
     1. 本期真实日期与星期 `{{dateDisplay}}`（如“今天是{{dateDisplay}}”，严禁照抄示例日期）；
     2. 主播自称 `selfName`（`deepseek` 自称“聪明的大肥鱼”，`gemini` 自称“哈基米”，`gpt` 自称“gpt”，`claude` 自称“小克”；严禁说自己是哪个公司的，严禁使用“XX娘”）；
     3. 顺带一句提示屏幕上的本期看点（如“今天看点都在屏幕上了”）并干脆收口进入正文，避免死板的“欢迎收看今天的AI每日报”电视腔；
   - 不同人设语气参考思路（仅作语气参考，须按本期真实 `{{dateDisplay}}` 现写，严禁照抄）：
     - `聪明的大肥鱼`：`["嗨各位，今天是{{dateDisplay}}，我是聪明的大肥鱼，今天看点都在屏幕上了，咱们直接开聊。"]`
     - `gpt`：`["各位好，今天是{{dateDisplay}}，我是gpt，本期看点都在屏幕上了，咱们直接进正题。"]`
     - `哈基米`：`["哈喽大家好，今天是{{dateDisplay}}，我是哈基米！", "本期看点都铺在屏幕上了，咱们直接开看！"]`
     - `小克`：`["大家好，今天是{{dateDisplay}}，我是小克，本期看点已经列在屏幕上了，咱们直接看正文。"]`
   - 单句内部严禁在中英文、数字、单位或标点之间滥用空格；附带一句简短带主播性格味儿的 `intro.hostComment`。
3. **干脆利落的性格收尾（`outro`）**：
   - **不做长篇趋势总结或说教升华**，开场已经自报过日期与家门，结尾直接结合本期真实看点加半句符合主播性格的轻吐槽，再自然道别即可（也可顺口带一句自称 `selfName`，不要说自己是哪个公司的，严禁使用“XX娘”）；
   - `outro.narration` 严格控制在 **1～2 句、总长 12～52 字**，例如：
     - `["今天的AI账就先算到这儿，咱们下期见。"]`
     - `["看了一圈全是算力和额度大战，我是小克，明早见。"]`
   - `outro.cta` 写一句克制自然的屏幕互动提示（如“哪一条最戳中你？欢迎在评论区聊聊。”），`outro.hostComment` 简短贴合角色性格。
4. **B 站投稿包装（`publish`）**：
   - **高点击率爆款标题写作规则（直接决定推荐流点击率）**：
     1. **强冲击开头与情绪钩子（大部分期次优先使用）**：当本期包含大厂发布/动作、模型更新、额度或价格大变动、开源突破、算力/硬件进展、融资上市或翻车争议时，**优先把强冲击词或情绪钩子放在标题最前面**，避免写成平铺直叙的死板通稿风；
        - 常用高转化冲击词库（结合下方「近期历史标题」轮换错开，避免连续两期重复同一个开头词）：
          - **行业重磅/大厂动向**：`AI圈大地震！`、`AI圈地震！`、`炸裂！`、`AI圈炸裂！`、`深夜炸裂！`、`AI圈沸腾！`、`头皮发麻！`、`彻底杀疯了！`、`核弹来袭！`、`大的要来了？`、`双巨头出手！`
          - **福利/免费/价格突破**：`直接白嫖！`、`额度翻倍！`、`价格打穿！`、`太狠了！`、`全员免费！`
          - **翻车/震荡/争议吃瓜**：`史诗级翻车？`、`冷汗直流！`、`硅谷震动！`、`铁拳出击！`、`社区吵翻了！`
        - 仅当本期全部新闻确实平淡琐碎、强用爆点词显得违和时，再退回“核心利益/数字反差直给”开头；**严禁**以 `AI每日报｜`、`AI早报：`、`今日AI资讯` 等栏目名开头，也**严禁**使用文件名下划线 `_` 代替空格或标点。
     2. **爆点词 + 硬核事实高密度结构（前 15～20 字定生死）**：冲击词后立刻紧跟最具体的公司/模型/产品名 + 关键数字、额度、涨跌幅、硬件门槛或反差结果，并用分号或逗号自然拼入 1～2 条最抓眼的高关注热点（以下例句仅学节奏与信息密度，严禁照抄）：
        - 例：`AI圈大地震！Antigravity重置全员Gemini额度提效22%；Anthropic上市次日暴跌9%拖累纳指`
        - 例：`炸裂！3060显卡本地跑125B模型每秒45.5个token；Suno上线15秒AI对口型视频工具`
        - 例：`直接白嫖！某旗舰模型实测免费开放每日20次额度；混元24GB小模型路线图同步曝光`
     3. **三档差异化候选策略（写入 `publish.titleCandidates`，并优先挑选最具点击张力的一条作为 `publish.title`）**：
        - **候选 1（情绪爆点 + 头条核弹档，默认主推）**：以 `炸裂！`、`AI圈大地震！`、`AI圈地震！`、`头皮发麻！`、`彻底杀疯了！` 等强冲击词开场，紧接本期最炸的 1～2 条硬核事实；
        - **候选 2（利益福利 / 夸张数字反差档）**：直接把免费额度、价格变动、本地消费级显卡门槛或倍率反差顶在最前面（如 `直接白嫖！`、`额度翻倍！`、`太狠了！` 或数字直接开局）；
        - **候选 3（争议吃瓜 / 危机悬念档）**：突出暴跌、封号限流、翻车、缺验证或行业博弈等痛点与悬念（如 `冷汗直流！`、`史诗级翻车？`、`社区吵翻了！`），拉高评论欲。
     4. **100% 事实与历史去重底线**：情绪词只用于强化传播张力，标题中的每一个公司名、模型名、价格、倍率、百分比、时间与状态，必须 100% 源自已过审新闻中的真实事实；未官宣爆料/灰测必须标明 `被曝`、`实测`、`疑似`、`灰测`；开头词与句式需与下方「近期历史标题」明显错开，避免连续多期撞脸。
   - **近期历史标题（本期标题在开头句式、关键词与风格上必须避开雷同）**：

   - `publish.title` 严格控制在 **18～72 字**（不得超过 `titleMax`），同时在 `publish.titleCandidates` 中输出上述 **3 个不同切入角度的合规备选标题**；
   - `publish.descriptionIntro` 写成简明的本期导览（**严禁包含任何网址 URL、域名、信息来源或出处链接**，避免 B 站外链违规风险）；

5. **视频封面文字（`cover`）**：
   - `cover.title`：**4～{{coverTitleMax}} 字**（不含星号与换行符），只抓头条里最炸的一个点，用“具体名字 + 动作/结果”的短句，主动在语义断点处用 `\n` 分成 2 行；可用一对 `*星号*` 包住 2～5 字核心词做高亮（最多一处）；
   - `cover.subtitle`：**8～{{coverSubtitleMax}} 字**，一句话补充最关键的数字、价格、反差或悬念，不使用星号；

6. **四阵营跨阵营互怼插嘴（`guestReactions`，可选，每期最多 2 条）**：
   - 从 `order` 中挑选 **0～2 条**最适合引发阵营吐槽的新闻（比如某大厂降价、涨价、跳票、开源或算力翻车），安排一位**与当期主播不同阵营**的角色（从 `deepseek`、`gpt`、`gemini`、`claude` 中选择且严禁与当期主播相同）插嘴补刀 **1 句短评**；

   - 若本期没有自然契合互怼的新闻，可留空数组 `[]`，宁缺毋滥。
