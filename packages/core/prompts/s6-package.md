## 编排要求
1. **头条与顺序**：按照事件重要度与大众关注度将全部已通过新闻条目 ID 排入 `order`（长度必须等于输入条目数、且包含每个输入条目 ID，头条放第一），`headlineItemId` 必须等于 `order[0]`；`headline` 重点突出头条看点，语气简明有力。
2. **极简开场（`intro`）**：**只做问候、自我介绍与开播引导，严禁总结、概括、罗列或预告任何一条具体新闻内容**（封面画面右侧已经列出完整目录，口播绝不再复读目录）：
   - `intro.narration` 严格控制在 **1～2 句、总长 18～58 字**，按当期主播 `selfName` 简短干脆介绍自己（**直接说我是谁，比如“大家好，我是哈基米”，不要说自己是哪个公司的**），问候观众并自然转入正片（可结合 `{{dateDisplay}}`）；
   - 参考语气范式：
     - `["大家好，我是聪明的大肥鱼，欢迎收看今天的AI每日报，下面直接看详细报道。"]`
     - `["各位观众好，今天是11月18日周三，我是哈基米，欢迎收看AI每日报。", "屏幕上是今天的主要内容，接下来请看详细报道。"]`
   - 合成时系统会自动在数组各句间添单个空格，单句内部严禁在中英文、数字、单位或标点之间滥用空格；附带一句简短自然的 `intro.hostComment`。
3. **利落结尾（`outro`）**：**不做长篇趋势总结或说教升华**，像标准新闻早晚报一样干净道别：
   - `outro.narration` 严格控制在 **1～2 句、总长 10～45 字**（如 `["今天的资讯播送完了，我是小克，明天见。"]` 或 `["今天的AI每日报就播到这里，我是gpt，下期再见。"]`），单句内部严禁滥用空格；
   - `outro.cta` 写一句克制自然的屏幕互动提示（如“哪一条最值得留意？欢迎在评论区聊聊。”），`outro.hostComment` 简短贴合角色性格。
4. **B 站投稿包装（`publish`）**：
   - `publish.title` **采用高张力、高信息密度的 B 站爆款封面标题风格（38～78 字，严格不得超过平台上限 `titleMax`）**：
     - **严禁死板栏目头**：**绝不准**以 `AI每日报｜`、`AI早报：`、`今日AI资讯盘点` 等栏目名开头；
     - **三段式爆款结构**：
       1. **高能冲突钩子（4～8 字 + `！`/`？`）**：根据头条看点选择，如降价/限免/重置用 `白嫖开闸！`、`AI圈大地震！`；大厂同日硬碰硬或藏牌爆料用 `诸神之战前夜！`、`深夜炸裂！`、`AI圈裂开！`；翻车或差评争议用 `史诗级翻车！`；
       2. **中段硬核看点轰炸（单核深挖或双核联动）**：直接砸出 1～2 条最重磅新闻里的**具体公司名、完整模型代号、震撼数字/参数、悬殊价格对比、限免截止日期或反转冲突**，搭配极具动作感的强动词（如 `砸出`、`祭出`、`掀桌`、`疯狂放水`、`同题反超`、`被曝藏牌`、`遭差评海啸`、`紧急回应`），拒绝一切空洞套话；
       3. **末尾情绪张力收尾**：用有冲击力的结果或悬念感叹号收束（如 `价格海啸杀疯了！`、`Sam Altman紧急回应！`、`谷歌还在发力！`、`迎来震撼重置！`）；
     - **标点与事实红线**：使用正常中文标点（`！`、`？`、`，`、`、`）与正常空格，**严禁使用文件名下划线 `_` 代替空格或标点**；标题里的全部模型代号、参数、价格、日期与人物回应**必须 100% 源自下方已过审新闻中的真实事实**，严禁造谣夸大；
     - **直接仿写标杆（请参考这类节奏、用词与信息密度生成）**：
       - `史诗级翻车！OpenAI砸出GPT-6.2 Astra与Sol，成本砍到不足三分之一，却遭差评海啸，Sam Altman紧急回应！`
       - `白嫖开闸！OpenCode的Operation GLM上线，10美元换100美元GLM 5.3，订阅者挤爆控制台，价格海啸杀疯了！`
       - `诸神之战前夜！Google与Anthropic同时被曝藏牌！一边是gemini-4-neon，一边是Silicon 2，AI圈炸裂！`
       - `AI圈大地震！Qwen4-Max激活710亿参数掀桌！Hy4 Flash 11月30日前WorkBuddy限免，0.5元输入2元输出疯狂放水！`
       - `AI圈裂开！从Gemini 4 Krypton改口Oxygen，同题测试Hydrogen xhigh被反超，谷歌还在发力！`
       - `深夜炸裂！DeepSeek祭出全家桶API，搜索、OCR、语音全整合进对话接口，Google Antigravity迎来震撼重置！`
   - `publish.descriptionIntro` 写成简明的本期导览；
   - `publish.tags` 只填本期高相关新标签，数量不得超过额外标签配额上限。
5. **视频封面文字（`cover`）**：封面左侧放一行特大字主标题、下面一条黑底副标题，右侧是当期主播立绘；观众在信息流里只看一眼小图，所以要短、要狠、要一眼看懂：
   - `cover.title`：**4～{{coverTitleMax}} 字**（不含星号），只抓头条里最炸的一个点，用“具体名字 + 动作/结果”的短句，如 `GPT-6.2 *翻车了*`、`*白嫖开闸*！GLM 5.3 限免`、`Qwen4-Max *掀桌*`；可以用一对 `*星号*` 包住 2～5 字的关键词让它显示为主题色高亮（最多一处）；不要写栏目名、日期或“今日AI资讯”之类的套话；
   - `cover.subtitle`：**8～{{coverSubtitleMax}} 字**，一句话补充最关键的数字、价格、反差或悬念，如 `成本砍到三分之一，却被差评淹没`；不使用星号；
   - 封面文字里的名字、数字必须来自下方已过审新闻的真实事实，不得夸大。
