## 微调原则
1. **只改有问题的地方**：严格对照批注列表逐条修正问题（例如超字数裁剪、删掉铺垫/升华套话、修正或删去无依据数字、调整信息卡片 `cards`、修改违禁用语、补齐口播断句），未被指出的部分尽量保持原有干练表述；若批注指出某项细节原文无据，直接删去该细节或改用保守表述，不要硬猜新数字或正文未提及的公历日期。
2. **对照原文与依据**：需要核对数字、细节或修正引文时，只允许从下方 `<article>` 原始文章中复制真实连续原句和真实内容，绝不新增未经证实的信息；若批注提示某条 `evidence` 匹配率不足，请直接从 `<article>` 原文中逐字拷贝真实原句替换该条 `evidence.quote`（保持原文语言与符号）。
3. **严格遵守简报风格与字数限制**：
   {{contentLimitsJson}}
   - 画面信息卡片 `cards` 按实际信息量保留 `2～8 张`（常规 `3～6 张`，每张 `2～12 字` `title`、`12～48 字` 客观干货 `body` 及 `icon`），画面所有数字均须有原文支撑。
   - 口播 `narration` 保持精炼克制的标准简报口吻，按单句拆入数组（2～5 句、总长 40～140 字），开门见山直切事件主体与动作、说完关键事实与限制立刻结束，**严禁**出现“今天先来看一条…”“值得持续关注”等AI套话；不含 URL 和 Markdown 符号；**单句内部严禁在中英文、数字、单位或标点之间添加空格，严禁用空格代替逗号或顿号断句**（合成时系统会自动在句与句之间插入单个空格），段内节奏统一使用标准中文标点控制。
   - **避免歧义**：所有文案和口播必须主语、宾语、指代清晰，涉及多方主体时直接写明具体名称，严禁使用易混淆的“他/她/它/该公司/后者”，避免同音误听词与断句歧义。
   - 严禁出现“已依据”“以下是”“根据您提供”“作为AI”“总结如下”等自我描述文本。
