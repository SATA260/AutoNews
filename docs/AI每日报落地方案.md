# 《AI 每日报》简要落地方案

> **核心目标**：不做“念官方通稿的第四只乌鸦”，而是用**稳健的早晚双更节奏 + 高人味口播 + 四阵营互怼 + 原文真凭实据截图**，把每期视频做成有活人感、高留存、高收藏的 AI 情报节目。  
> **执行原则**：先用 2 周把**稿子人味、开场/结尾节奏、黑鸦标题 Skill、早晚双更策略与合规简介**跑顺并验证数据，再推进**白鸦式抓取与自动截图优化、封面升级与四阵营互怼**。

## 分阶段怎么落地（照着做就行）

### 第一阶段（第 1–2 周）：先把“人味、标题、节奏、合规”调顺

这一步**不动底层架构**，优先解决最新两期“机器味重”和发稿策略问题：

1. **彻底给稿子“去机器味”（最高优先级）**
   - **怎么做**：把**之前观感自然的老期稿件**和**最新两期机器味重的稿件**并排对照，找出变呆板的具体原因（通常是提示词里塞了太多硬性结构模板、总结句或书面语要求）；改写 `packages/core/prompts/s4-polish.md`，强制要求短句化、口语化、带一点真实使用者的主观情绪和吐槽感，彻底拉黑“值得注意的是、令人瞩目的是、综上所述、标志着”等典型 AI 套话。
   - **为什么**：口播人味是一切的底座，尤其后面要做四阵营互怼，底稿如果像机器翻译腔，互怼只会显得尴尬。
2. **开场直抛结论，结尾再说“我是谁”**
   - **怎么做**：改 `packages/core/prompts/s6-package.md`，开场第 1 句直接讲头条最炸裂的变化或用户最关心的结果，绝不寒暄；把主播自我介绍移到片尾收口（例如“我是小克，咱们今晚/明早见”）；同时把篇幅从“条条平均 25 秒”（如 [11 月 20 日晚间成片](https://www.bilibili.com/video/BV1NHysz3Ew7/)）改成**头条 35–45 秒讲透、次要短讯 10–15 秒带过**。
   - **为什么**：二创立绘大家本来就认得出是谁，开场不需要靠自我介绍建立认知，把前 5 秒全留给干货才能拉高 30 秒留存；结尾再报名字既完整又有记忆点。
3. **标题直接上“黑鸦标题 Skill”**
   - **怎么做**：把黑鸦的爆款标题结构（强利益点/免费额度/封号限流痛点/型号对比反差 + 紧迫感）封装成一套可复用的**黑鸦标题 Skill**，接到 `s6-package` 阶段自动生成 3–5 个候选标题，审核时一键选最抓人的版本，同时守住“未证实消息标明爆料/实测”的底线。
   - **为什么**：不用每次靠人工现想，直接复用已被 B 站算法验证过的高点击率标题范式。
4. **定死早晚双更 + 合规简洁的简介**
   - **怎么做**：
     - **发稿节奏**：固定每天早、晚各 1 期，不为了追热点一天连发三四条导致 B 站限流；遇到旗舰模型发布等 S 级大事，直接把最近那一档早报或晚报改成“大事单拆/主推版”吃满流量。
     - **简介规范**：改 `packages/core/src/publish/description.ts`，**绝不放外部网址链接**（防违规下架），核心放清楚**免责声明**（说明由 AI 辅助整理/配音，内容仅供参考，以官方发布为准）和基础时间轴；如果某条工具或项目值得观众去试，直接把**项目名/平台名/搜索词**用大号标签打在视频画面里。
   - **为什么**：安全第一，简介本来就没人细看，承担好合规免责职责就行；把实用信息留在画面里，观众截图收藏才顺手。

### 第二阶段（第 3 周）：结合白鸦工作流，把“抓取 + 截图 + 封面”自动化做扎实

稿件人味和点击率跑稳后，集中补齐工程与视觉效率：

1. **参考白鸦工作流，升级信息抓取与自动截图**
   - **怎么做**：
     - **抓取侧**：在 `config/sources.yaml` 补齐 GitHub Trending（AI 飙升项目）、Reddit（`r/LocalLLaMA` 等）、`Linux.do`/V2EX 热帖及主流厂商 Status 页，并在抓取链路中记录“官方发布 -> 采集 -> 选题 -> 审核 -> 发布”耗时，压缩中间空等（避免像之前混元开源那样晚 11 小时才发）。
     - **截图侧**：改造配图采集流程，对官方博客正文、价格/限额表、GitHub 仓库卡片、社区高赞实测贴做**自动定位裁切与去弹窗干净截图**，直接作为分镜底图或证据插图，减少“随便配一张泛泛而谈的图”的情况。
   - **为什么**：白鸦单篇能打出高收藏，核心靠的是“真信息源 + 一手截图证据”；把这套抓取和截图流程自动化，既提画质又省人工。
2. **封面保留二创辨识度，叠加事件视觉锤**
   - **怎么做**：在 `templates/cover-card/` 保留大家一眼就能认出的二创立绘，不再过度缩小，同时给大字标题（4–8 字核心钩子）和品牌标志留出清晰视觉重心；常规早晚报与 S 级大事件专场用不同底色区分。
   - **为什么**：既不浪费现有二创角色的高辨识度，又能让刷推荐流的观众 0.3 秒看懂这期讲什么大事。

### 第三阶段（第 4 周）：四阵营互怼上线，拉开互动护城河

1. **让四阵营真的“怼”起来**
   - **怎么做**：在 `s4-polish.md` 和 `s6-package.ts` 中，为每期最具争议或戏剧性的头条增加可选的 `guestReaction`（18–35 字，每期 1–2 处即可，不喧宾夺主），调用对手阵营主播的音色，在 `templates/daily-deck/` 侧边弹出半身立绘和吐槽气泡（例如哈基米刚吹完新模型，小克立刻冷冷补刀问上下文限制，或者大肥鱼跑出来算一笔 API 价格账）。
   - **为什么**：建立在第一阶段已经拉回“人味”的稿件基础上，四阵营轻互怼能瞬间激活 B 站最缺的弹幕站队和评论区玩梗；若后续配音同步升级到带语气词控制的高表现力模型（如 MiniMax `speech-2.8-hd`），活人感会再上一个台阶。
2. **结构化对比卡 + 4K 高码率输出**
   - **怎么做**：为 `templates/daily-deck/` 补充“模型价格/参数/额度对比表”模板和官方演示短片静音循环槽；渲染层保持 `1920x1080` 布局，开启 `deviceScaleFactor: 2` 输出 4K（或先试 2K）。
   - **为什么**：配合第二阶段优化后的自动截图，4K 码率能让网页文字、代码和价格表清晰锐利，直接拉高技术向观众的收藏意愿。
