# 公司 Logo 资产目录

本目录用于存放开头总览瀑布流与新闻条目标识所需的公司 / 机构 Logo，系统已预置 54 家主流国内外 AI 与科技厂商的高清矢量 Logo（`.svg`）。

## 如何新增或替换公司 Logo

1. **直接投放文件**：将公司 Logo 图片放到本目录下，支持 `.svg`、`.png`、`.webp`、`.jpg` / `.jpeg` 格式。同文件名主干时，系统优先选用矢量 `.svg` 文件。
2. **文件命名即自动识别**：
   - 如需覆盖内置厂商图标，直接用对应规范文件名替换即可（如 `openai.svg`、`google.svg`、`alibaba.svg`）。
   - 如需新增未收录公司，将文件名主干直接命名为公司名即可自动匹配（例如 `范式智能.png` 或 `4paradigm.svg`）。
3. **配置别名映射（可选）**：
   如果文件名使用英文标识，但新闻中的主体名称同时存在中文或简称，可以在同目录的 `aliases.json` 中填写「别名 -> 文件名主干（不含扩展名）」映射，例如：
   ```json
   {
     "第四范式": "4paradigm",
     "范式智能": "4paradigm"
   }
   ```
4. **缓存自动刷新**：增删改本目录下的图标或 `aliases.json` 后，下次渲染会自动重新生成封面视频分片，无需手动清理缓存。
