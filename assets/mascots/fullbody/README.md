# AI 每日报全身 Live2D 看板娘

将角色的整套目录解压到本地，在支持 Cubism 4 模型和动作组的查看器里打开入口文件。模型、贴图、物理、表情和动作均使用相对路径。

| 角色 | 入口 | 全身动作 |
| --- | --- | --- |
| DeepSeek 娘 | [deepseek.model3.json](deepseek/deepseek.model3.json) | 招手、重心转移，鲸耳和鲸尾随动 |
| GPT 娘 | [gpt.model3.json](gpt/gpt.model3.json) | 左手示意、回正，白裙、龙翼和龙尾随动 |
| Gemini 娘 | [gemini.model3.json](gemini/gemini.model3.json) | 轻快挥手、重心转移，猫耳、猫尾和裙摆随动 |
| Claude 娘 | [claude.model3.json](claude/claude.model3.json) | 右手致意、微微点头，长发、裙摆和腰带随动 |

| 动作组 | 内容 |
| --- | --- |
| `Idle` | 循环待机，含呼吸、眨眼、微调站姿 |
| `Talk` | 用内置节奏预演口型。接入真实语音时，由宿主写入 `ParamMouthOpenY` |
| `FullBody` | 8 秒全身动作，使用肩、肘、腕、髋、膝和踝的参数 |

可动幅度按立绘里的原有姿态和遮挡设定。腿脚支持站姿和小幅重心变化，长裙遮住的腿部主要通过裙摆和露出的鞋履表现。肩、肘、腕、髋、膝、踝的参数范围是 −1 到 1。实际参数名和部件名可见各角色的 `.cdi3.json`。

四位角色的底图都已移去原来的双臂。手臂从肩部到指尖分别重绘并绑定肩、肘和腕，前发有自己的图层。DeepSeek 补齐袖子后面的蓝发和衣料，胸前白色褶边盖在袖子上方。GPT 补齐原来被袖子遮住的白发和龙翼，Claude 补齐披肩下方的长发并单独保留带太阳纹的披肩。袖子的外形和配色参考原立绘，用内置 ImageGen 补绘。分层 PSD 可用来检查底图、双臂及遮挡层，运行绑定保存在 `.moc3`。
