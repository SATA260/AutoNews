# AI 每日报看板娘素材目录

本目录按用途拆分存放静态立绘与两套 Live2D 模型，便于按配置切换与独立维护：

- 根目录静态立绘（`claude.png`、`deepseek.png`、`gemini.png`、`gpt.png`）：用于视频封面生成、管理台角色选择器与无头/异常场景下的静态兜底展示。
- [fullbody/](fullbody/README.md)：**全身动作版 Live2D**（当前默认绑定），在保留呼吸、眨眼、实时口型、情绪切换与多组摆动物理的基础上，支持肩、肘、腕、手部与腿部/重心全身动作。
- [expression/](expression/README.md)：**仅表情版 Live2D**，轻量保留头部微动、呼吸、眨眼、实时口型与情绪表情切换，不包含大幅度双臂重绘动作。
